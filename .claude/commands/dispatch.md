description: The morning dispatch: today's sheet, what grounds an aircraft or a student, and flights still to grade from yesterday
---

Run `npm run school -- today --json`, `npm run school -- fleet --json` and `npm run school -- ungraded --json`. Present one sheet: each booking with go or fix-first, aircraft status, and debriefs owed. Nothing changes from this command.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.
