---
description: Grade a flight and record the debrief: competent, repeat or incomplete. Once only
---

Run `npm run school -- grade <flight> competent|repeat|incomplete --grade=1-5 --debrief="what was covered and what is next"`. Write the debrief in the instructor's words. A graded flight is never rewritten: corrections go in a note with `/log`.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.
